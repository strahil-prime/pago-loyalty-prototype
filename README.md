# PagoEfectivo Loyalty Phase 3 – clickable prototype

Static, image-based iOS prototype for UserTesting.com concept tests. Open `index.html` (or the deployed URL) on a phone.

- Start screen: Home. Optional deep links: `#puntos`, `#stores`, `#cip_code`.
- Task A: "How many points do you have and where can you use them?" (Puntos tab, Canjear, Mis premios, sweepstake).
- Task B: "Pay this Temu CIP using your points." (Home → Pagar → Continuar → choose a discount → Pagar).
- Screens are 2x exports from the Figma file, with text corrections applied; hotspots are defined in `index.html`.
